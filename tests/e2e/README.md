# Браузерные E2E-тесты

Команды для запуска из корня проекта.

```sh
npm ci
npm run test:e2e:install
npm test
npm run test:e2e
```

Playwright собирает временную копию сайта через `scripts/build-production.py`
и запускает её на `127.0.0.1:4173`. Для запуска нужны Node.js 20+ и Python 3.9+.
Каждый тест получает отдельный браузерный контекст. Внешние запросы страниц
блокируются. Тесты заявок подставляют ответы CRM и проверяют данные на тестовых
контактах.

В матрицу входят Chromium, Firefox и WebKit на десктопе, мобильные Chromium
и WebKit, а также планшетный WebKit. Проверки охватывают навигацию, локализацию,
слайдеры, изображения, оба каталога, фильтры, планы, заявки и SEO-страницы.
Действия, доступные только на некоторых размерах экрана, выполняются в
подходящих профилях. Эмуляция размеров и ввода работает в браузерах Playwright.

Параметры после `--` позволяют выбрать профиль или файл.

```sh
npm run test:e2e -- --project=mobile-webkit tests/e2e/catalog.spec.mjs
npx playwright show-report
```

HTML-отчёт находится в `playwright-report/`, а JSON и снимки упавших проверок
в `test-results/`. Временный сервер отдаёт те же файлы под `/preview/` для
проверки путей при размещении сайта в подпапке.
